## 第二階段落地範圍

- 純TypeScript資料模型與JSON驗證獨立於React。格子、全局欄位允許未知，人工更改來源標為manual，不填假信心值；匯入一律需重新確認。
- 真實遊戲自動定位／物種／品質辨識仍缺少可靠、可公開使用的標註樣本，**目前真實圖片保留未知**，可手動選ROI並建立盤面。
- 自製測試圖以四角校準色塊、格子種類／品質色碼測試定位與切格；不是遊戲圖示識別率測試。測試圖是本專案自製，象獅狼鼠SVG也為新繪的簡單線條圖示。
- 保守模式只呈現使用者確認的巡視候選，不宣稱可再執行一次或最佳步。實驗模式檢查同品質／指定食物鏈，且僅在明確無刑具、無特殊標記／事件時顯示；每日次數、距離、連鎖仍未知，必須顯示非正式保證。
- 規劃器介面保留budget與AbortSignal；本階段不執行Monte Carlo或MCTS。

## 正式開服後優先驗證

1. 完整20天操作錄影：phase、換與吃的次數／順序、巡視可選數與位移規則。
2. 位置1角色與可容納牢房數，透視／UI縮放下的逐格ROI。
3. 四條vs六條克制、每階吞食條件、隨機代號分布、連鎖目標及中止。
4. 清晰且可公開使用的圖示／鎖格／品質／標記樣本與負樣本，持出不同解析度作評估。
5. 刑具例外、事件順序、綺彩容量、鎮壓失敗與秘藏掉落；不以民間模擬量代替實測。
