# 影片回放與資料集測試

版本2026.10.15.4；日期2026-10-15。

## 使用流程

1. 第二區塊展開「影片回放測試模式（本機）」，匯入512 MiB內 MP4／WebM。實際編碼須由瀏覽器支援；不能解碼時顯示錯誤。
2. 用播放器播放／暫停／時間軸，或輸入秒數與前／下一格。逐格是以人工FPS換算時間；可變幀率不保證精確原始影格索引。
3. 點「擷取並分析此影格」才截圖並暫停影片。預設真實遊戲模式缺少可靠模板時保持未知。原創色碼素材須明確切換測試模式。
4. 下方「修正盤面」核對任意格子與全局資料，完成後「確認整個盤面」。未知仍可保持未知。
5. 儲存標註影格，或記錄操作前／後，填實際動作、驗證狀態、證據限制，儲存操作紀錄。操作後時間不可早於操作前。
6. 匯出資料集JSON、下載標註PNG；重新匯入可載入標註盤面再修正。資料集含圖片，公開前自行檢查私人內容；完全沒有自動上傳。
7. 「重新辨識資料集並計算準確率」可重跑本機回歸、取消則保留舊結果。關閉／重新整理／匯入新影片會清除未匯出資料。

## 資料結構

`src/video/history.ts` 的 LabeledFrame 保存時間、原圖PNG、辨識模式、選區、辨識原始盤面及人工標註盤面；Operation 保存操作前後完整快照、資源、實際動作、時間、驗證標記與說明。boardDiff 比較16格及天數／典獄長／巡視／刑具／資源／已收容囚犯，排除確認時間與影像信心等非遊戲變化。

JSON schemaVersion=1、kind=test14-video-dataset；最多50影格／50操作、每PNG base64字串4MB、全文25MB。嚴格驗證盤面、enum、時間、選區與PNG data URL，不允許遠端圖片URL。匯入後盤面須重新確認。使用者選「已驗證」只代表本次觀察，evidence始終為 user-annotation，不提升為官方規則。既有rules.ts／StrategySolver介面與實驗規則隔離繼續沿用，未新增最佳策略或隨機掉落數值。

## 測試素材與數量

`public/fixtures/` 為本專案自行製作、CC0釋出的3秒影片，一份內容、MP4及WebM兩種編碼，不是兩段獨立實戰。0.5秒與1.5秒為兩個色碼盤面，第二格獅改為鼠；2.5秒為無效黑畫面。附PNG、獨立預期盤面JSON及manifest。產生腳本為scripts/generate-video-fixtures.ts，需要自行提供官方FFmpeg執行檔；不作為網站執行期依賴。

先前研究紀錄主要是影片網址與未確認散布權的畫格，無可直接公開的正式遊戲影片。本次沒有複製第三方遊戲素材。**實際遊戲影片測試數0；真實遊戲辨識率未知。**

## 結果與限制

- 純像素測試：獨立預期盤面在0.5／1／1.5倍尺寸，每張25個已知欄位，共75/75；黑畫面與game模式不套用測試色碼。這是測試協定驗證。
- 瀏覽器實測：MP4、WebM均成功解碼3秒、手動選時擷取。WebM兩張盤面人工核對已知欄位並重跑回歸50/50；3個未知格不計分。此為原創素材，不能外推遊戲準確率。
- MP4案例：壓縮色偏造成校準框檢查未通過，結果保留未知；尚未提高容差，避免為提高數字放寬辨識。列為已知失敗案例，應補人工選區／標註。
- 操作前0.5秒／後1.5秒、1筆unknown標記紀錄、資料集JSON下載與重新匯入已實際操作。標註PNG已由本機正式建置頁下載並視覺檢查；中文種類、品質、位置及時間標註符合測試盤面。
- 種類／狀態／品質以人工已知值為分母；漏辨識計為錯誤；未知標註不計分，無標註時顯示無可評分資料。覆蓋率與錯誤格列表獨立顯示。
- 正式開服後須蒐集取得授權、不同解析度／UI／動畫／遮擋／前景背景的實際素材與人工獨立標註，再公布遊戲準確率。未知規則不能由測試素材驗證。


自動化回歸另從browser-webm-dataset.json解碼兩張瀏覽器PNG的像素，以目前recognizeRaster重新定位及分類，對照獨立expected-before／after.json；25+25欄位通過，演算法後續改動由CI重跑此測試。PNG解碼輔助程式只處理可信測試素材，不用於網站輸入。
