# 最佳化演算法評估（設計研究）

沒有實作、沒有性能實測。依現有證據提出可驗證的路線，不能把下列時間預算說成已達成。

## 問題型態

目前較適合研究「單人、有限期限、有隨機結果的序列決策」，不宜先建成對抗式棋類。升阶隨機代號有 [前瞻摘要](https://shouyou.gamersky.com/news/202610/2225220.shtml)支持；模型另含未開牢房、隨機交換、事件，須獨立驗證。[CoffeeBns](https://www.youtube.com/watch?v=BYO4wMcf5jQ&t=9s)也承認模型與真實規則可能不同。

- **完全資訊？** 尚不能認定。演示有鎖格，是否藏囚犯未知；未來隨機結果不可見不代表必然是部分可觀察：若當前足夠狀態可見且轉移分布已知，仍可建MDP。只有存在影響決策的隱藏當前狀態才需要belief／POMDP處理。
- **合法行動數？** 未量測，依phase分開。目的地候選、交換、吞食對象、刑具選擇與刷新不能未經規則確認就做笛卡兒積。
- **終點？** 20天不等於搜尋深度20；日內多步決策、連鎖與事件增加深度。可能同日轉移，需要完整phase與剩餘次數。
- **完整窮舉？** 未知。先量測 `b(s)`、隨機分支 `c(s,a)`、狀態重合率與有效深度；粗略節點量隨 `(b*c)^h` 增長，不能僅因20天就宣布可／不可窮舉。
- **重算？** 建議每次操作後重新觀測。升阶、開門、事件或工具改變狀態後，先前長連鎖計畫可能失效；不能預知下一個隨機結果再選動作（避免clairvoyant simulation）。

## 方法比較

| 方法 | 適用性 | 優點 | 失敗風險／目前結論 |
| --- | --- | --- | --- |
| Greedy | 可信局部規則的基準／低耗時模式 | 容易解釋，列舉合法行動後快速評分 | 忽略素材消耗與未來組合；作者模型推薦不證明全局最優 |
| Minimax / Alpha-Beta | 只有確實存在對抗者最壞策略時才自然適用 | 可分析明確最壞情境 | 隨機重抽不是敵手；不能將min代替概率平均。若概率已知用chance／expectimax，常規alpha-beta界限不直接套用 |
| Monte Carlo Simulation | 規則可正確抽樣後，為候選行動作rollout比較 | 簡單、可固定計算預算，容易報估計誤差 | 模型偏誤無法靠增加樣本消除；未知概率不能裝成已知 |
| MCTS | 多步相依、分支多且rollout有效時研究 | 計算能集中到较有潛力分支 | 需要正確機會節點、狀態／樣本共享；稀有事件與長鏈造成方差。先和MC比較，不預定獲勝 |
| Dynamic Programming | 小型局面、短剩餘期限、離散狀態且有已知轉移 | 可當局部精確oracle，memoization复用狀態 | 完整狀態或隱藏belief巨大；错误合併位置／標記會改變規則 |
| Beam Search | 可用局面啟發評分、希望固定寬度前瞻 | 控制記憶體與時間 | 剪掉暂时低分的長鏈；随机结果应加权／抽樣，不能只留最幸運後繼 |

方法背景參考 [Browne等，2012 MCTS綜述](https://cs.gettysburg.edu/~tneller/cs371/mcts-survey.pdf)。表中對本遊戲的適用判斷屬研究推測。

## 有限期限方程（條件性模型）

在狀態充分、行動與概率都已確認時：

`V(s) = max over a [ r(s,a) + Σ P(s'|s,a) V(s') ]`

狀態必須包含day、phase及日內剩餘機會；終局評分因A/B/C不同，不能共用純綺彩數。事件內不消耗天數時也不能錯誤減一天。若重抽是隱藏的未來結果，rollout內后續政策只能讀當時觀測。

## 建議研發順序

1. 先取得合法行動與轉移規則、品質表和全部例外；未確認則停止給「最佳」建議。
2. 以小局面精確DP／枚舉建立oracle；對照演示前後狀態。
3. 實驗Greedy、短深度Beam、固定預算MC；相同種子与持出测试集比较，训练／测试分开。
4. 只有前述方法在相同延迟下仍明显吃亏，才引入带chance节点MCTS。
5. 自動連鎖如果不可打斷，可壓縮成macro transition，但必須保留目標與升階隨機分布；不能壓成確定結果。

研究目標可設定：圖片解讀之外，規劃p95在250–1000ms內，提供立即基準與後續改進。這只是待測預算；記錄硬體、候選數、rollout次數、深度、耗時、分數差及模型版本，不能承諾瀏覽器已達到該速度。

優先效用應輸出預期值、風險與替代選项，僅差距超過抽樣误差及模型不確定性時宣稱明顯較好。否則提供近似並列，快速模式選較少操作者。
