## 20天與每日行動

目前沒有連續校對一局的20次日切換。不能給出「第N天一定有特定事件」的日曆，也不能斷言每次按鍵消耗一天。

| 天數 | 現階段能回答的操作／限制 |
| --- | --- |
| 1 | 開局與首輪目的地／囚犯狀態需要完整演示；換、吞食次數未知 |
| 2 | 目的地、刑具與囚犯狀態依局面；固定事件未知 |
| 3 | 同上；是否有限時工具獎勵未知 |

需要拆出日內phase：目的地選擇→抵達效果→事件／工具選擇→交換／吞食→自動連鎖→日結。**這是待驗證的狀態機草案，不是已確認順序**；其中是否可交換後再吞食、是否能跳過、是否每段可重做都未知。

## 不能偷渡為規則的模型設定

[CoffeeBns模型README](https://github.com/blahdot3h/tartarus-simulator)包含每日換／吞次數、克制鏈、鎖格可見性等實作，但頁面明示部分是練習值，與中文模型不同。這些應存入「simulation-hypothesis」，不得進入「live-rule」；其12天合約／運送模式亦不得套入20天玩法。

目前未確認完整品質順序、升階所需吞食數、種群克制矩陣、位置限制、自動目標選擇、連鎖能否中止與特殊標記效應。不能把一般斗獸棋規則自動套用。
